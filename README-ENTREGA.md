# Entrega Final - Projeto Web

## Atividade solicitada pelo professor

A atividade exigia a finalização do projeto Web desenvolvido durante a disciplina, incluindo:

- um formulário funcional relacionado ao tema do projeto;
- pelo menos três campos no formulário;
- campos com rótulos em HTML (`label`);
- botão de envio;
- organização visual com CSS;
- validação com JavaScript;
- mensagens de erro e sucesso para o usuário;
- uma interação adicional com JavaScript, como menu interativo, tema, modal, FAQ ou outra funcionalidade ligada ao projeto;
- revisão da estrutura geral do site, incluindo responsividade, organização visual e navegação;
- manutenção da consistência da interface, links, imagens e funcionamento geral.

A proposta principal era entregar uma versão completa, revisada e funcional da interface, sem necessidade de envio real para servidor.

## O que foi implementado

### 1. Formulário funcional

Foi adicionado ao projeto um formulário de contato integrado à página inicial, com:

- nome completo;
- e-mail;
- área de interesse;
- telefone;
- mensagem.

Esse formulário está relacionado ao tema da plataforma e faz sentido dentro do contexto de apoio a empreendedoras.

### 2. Validação com JavaScript

A validação foi implementada no arquivo `js/script.js`, verificando:

- campos obrigatórios vazios;
- e-mail em formato válido;
- seleção de área de interesse;
- mensagem preenchida;
- exibição de mensagens de erro e sucesso para o usuário.

### 3. Interação adicional com JavaScript

Adicionada uma funcionalidade de alternância de tema claro/escuro, permitindo ao usuário:

- trocar entre tema claro e escuro;
- manter a preferência salva no navegador;
- melhorar a experiência visual da interface.

### 4. Revisão visual e responsividade

Também foi ajustada a organização visual da página inicial, incluindo:

- cabeçalho com botão de tema;
- melhor estrutura de navegação;
- espaçamento e layout mais equilibrados;
- seções com estilo coerente;
- responsividade para telas menores;
- manutenção da identidade visual do projeto.

## Arquivos principais envolvidos

- `index.html` - estrutura da página principal e formulário
- `css/style.css` - estilos visuais, responsividade e layout
- `js/script.js` - validação e interação com JavaScript

## Resultado

O projeto final atende aos requisitos da atividade de entrega final, com interface funcional, formulário validado e interação JavaScript aplicada de forma coerente ao tema do site.
